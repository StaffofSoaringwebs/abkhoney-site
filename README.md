# Aussie Bee's Knees Honey — advert landing pages

Five static landing pages, one per Facebook advert, served at https://abkhoney.com.au

Built by Soaringwebs. The source of truth for content and build is
`output/websites/beesknees-ad-pages` in the Chester repository — edit there, not here.

Each page is self-contained: one inline stylesheet, one image, no external JavaScript.
The product photographs are AI-generated images of the client's own jar, which every
page states plainly in its footer.
